This is the traffic light system which generally goes from red to yellow (steady amber) to green and after a while goes from green to amber to red (and the cycle continues on). 

Red: Warns the vehicles to stop.

Red-amber: Signal that prepares the vehicles to leave the traffic light line

Green: 'GO!' so the vehicles can go now

Amber: warns the vehicles to be prepared to stop by the time the traffic light reaches red

Red: Warns the vehicle to stop (back to the start).
